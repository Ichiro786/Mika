## What it is
A globally used instant-messaging service. The web version `web.whatsapp.com` shares the same account with the phone and desktop apps.

## Pages and URLs
Web entry `https://web.whatsapp.com/`. When not linked, the page shows a QR code; scan it with the phone's WhatsApp "Linked devices". After sign-in, the left side has the conversation list with search and a new-chat button, and the right side is the chat window. The UI language follows the browser.

## Features
- **Reading**: the conversation list shows the title and last message; open a conversation to see the body and times, and in group chats the speaking member.
- **Sending**: in an existing conversation type in the box at the bottom and send; for a new chat go in through New chat or by searching contacts.

## Known behavior
Linked-device sign-in uses a QR code, which is a different verification from the phone-number code. With the newer linking method the phone does not always need to stay online.
